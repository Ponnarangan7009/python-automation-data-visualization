# Python Automation Data Visualization

Small, practical learning examples for Python data analysis and visualization. The project progresses from Pandas Series and DataFrames to CSV/Excel processing, automation test summaries, and Matplotlib charts.

## Project structure

```text
.
├── automation_visualization/   # Pandas analysis and charts from automation results
├── LEARNING_REFERENCES.md      # Suggested reading and official documentation links
├── matplotlib_understanding/   # Standalone Matplotlib examples
├── pandas_automation_exercise/ # CSV summary and filtering exercise
├── pandas_understanding/       # Pandas fundamentals and CSV/Excel exercises
├── requirements.txt
└── verify_lib_version.py       # Check that dependencies import correctly
```

CSV files in the learning folders are source/sample data and are kept in the repository. Scripts write generated reports beside their source data; generated charts, Excel workbooks, and other report exports are excluded from Git.

## Requirements

- Python 3.10 or newer
- pip

## Setup

From the repository root, create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

On Windows PowerShell, activate with `.venv\Scripts\Activate.ps1`.

## Usage

Run scripts from the repository root. Each script resolves its input files from its own folder, so the working directory does not affect which sample data is read.

```bash
python verify_lib_version.py
python pandas_understanding/series_dataframe.py
python pandas_understanding/csv_exercise.py
python pandas_understanding/excel_csv_exercise.py
python pandas_automation_exercise/automation_report.py
python automation_visualization/automation_visualization.py
```

The Matplotlib examples open chart windows; run any one with:

```bash
python matplotlib_understanding/matplotlib_compare_apps_mem_bar.py
python matplotlib_understanding/matplotlib_compare_apps_mem_linear.py
python matplotlib_understanding/matplotlib_horizontal_bar.py
python matplotlib_understanding/simple_matplotlib_app_mem.py
```

## Generated outputs

- `pandas_understanding/excel_csv_exercise.py` writes `failed_tests.csv` and `failed_tests.xlsx`.
- `pandas_automation_exercise/automation_report.py` writes passed, failed, slow-test, and execution-summary CSV reports.
- `automation_visualization/automation_visualization.py` writes three PNG charts and `slow_test_report.csv`.
- The two comparison scripts in `matplotlib_understanding/` save `app_performance_report.png` in that folder.

These outputs can be regenerated by running the relevant scripts and are ignored by Git. Keep the supplied CSV sample data to run the exercises.
